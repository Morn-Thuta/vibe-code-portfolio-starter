# 💬 Vibe Coding Prompt Ideas

Copy, tweak, and paste these into **Copilot Chat in Agent mode**. **Be specific**: the more you tell it about yourself and the look you want, the better the result.

---

## 1. Make it yours (do this first!)

> My name is ___. I'm a ___ student at ___. I'm interested in ___ and my hobbies are ___. Update `index.html` with my real info in the hero, about, and footer sections. Keep the tone friendly and confident.

> Here are 3 projects I've done: (1) ___, (2) ___, (3) ___. Replace the placeholder project cards with these, and write a 1–2 sentence description for each.

> My skills are: ___. Update the skills section.

> Replace the contact links with my email ___, GitHub ___, and LinkedIn ___.

## 2. Change the look

> Change the colour scheme to ___ (e.g. "dark green and cream", "pastel pink", "neon cyberpunk"). Only change the CSS variables in `:root` and `[data-theme="dark"]`.

> Use the Google Font ___ for headings and ___ for body text.

> Make the design feel more ___ (minimal / playful / bold / retro / professional / brutalist).

> Make the hero section more eye-catching. Add a subtle animated gradient background.

## 3. Add features

> Add a smooth fade-in animation when each section scrolls into view.

> Add a hamburger menu for mobile so the nav links don't disappear on small screens.

> Add a typing animation to the tagline that cycles through: "student", "developer", "designer".

> Add an "Experience" section with a vertical timeline for my CCAs, internships and part-time jobs.

> Add a "Download my resume" button that links to `assets/resume/resume.pdf`.

> Let me filter the project cards by tag (e.g. "All", "Web", "Python").

> Add a contact form using Formspree (no backend needed).

## 4. Polish

> Check my site for accessibility problems (contrast, alt text, keyboard navigation) and fix them.

> Make sure the site looks good on mobile, tablet, and desktop.

> Add Open Graph meta tags so my site shows a nice preview when shared on LinkedIn or WhatsApp.

## 5. When things break

> Something broke after the last change: ___ (describe what you see). Please fix it without changing anything else.

> Explain what the code in `js/main.js` does, line by line, like I'm a beginner.

---

## 🧠 Tips for better vibe coding with Copilot

- **Use Agent mode.** Ask mode only answers questions. Agent mode actually edits your files.
- **One thing at a time.** Big vague prompts give messy results.
- **Point at files with `#`.** e.g. `#style.css make the project cards lift up on hover`.
- **Show, don't just tell.** Drag a screenshot of a site you like into the chat: *"make my hero look like this"*.
- **Keep or Undo.** Check the browser (Live Server refreshes by itself) before clicking **Keep**.
- **Start a new chat** (the **+** button) when switching to a different task. Long chats get confused.
- **Commit often.** After each win, commit in the Source Control tab so you can always go back.
- **Ask it to explain.** You'll learn way more if you understand what it wrote.
