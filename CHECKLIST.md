# ✅ Portfolio Checklist

Tick these off before you share your link.

## Content
- [ ] My real name is in the title, hero, nav logo and footer
- [ ] About section is written by/about me (no placeholder text left)
- [ ] My own photo is in `assets/images/` and shows up
- [ ] At least 2 real projects with descriptions and links
- [ ] Skills list is accurate
- [ ] Contact links go to my real email / GitHub / LinkedIn
- [ ] Searched for `TODO`, `Your Name` and `example.com` and replaced them all

## Looks
- [ ] Works on my phone (or browser dev tools → mobile view)
- [ ] Dark mode still looks good
- [ ] Text is easy to read (good contrast, not too small)

## Git & GitHub
- [ ] I've made at least 3 commits with clear messages
- [ ] Everything is pushed (`git status` says "nothing to commit, working tree clean")
- [ ] My site is deployed on Render and the `.onrender.com` link works
- [ ] I pushed one more change and saw Render redeploy it automatically
- [ ] I've put my live link in the repo's **About** section on GitHub (⚙️ next to "About")

## Bonus
- [ ] Added a feature that isn't in the starter (animation, timeline, filter, form...)
- [ ] Shared my link with a friend and they could open it 🎉
